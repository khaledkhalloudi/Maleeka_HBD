MALEEKA'S BIRTHDAY SURPRISE — TAP-THROUGH EDITION

This website now opens one chapter at a time, with a button to continue to each next chapter:
1. Open your surprise
2. A letter in gold
3. Six frames. One beautiful story
4. A wish for your next chapter

FILES
- index.html: website content
- style.css: black-and-gold luxury styling and animations
- script.js: chapter navigation, rose-petal effects, photo lightbox, final wish
- photos/: six photos used in the gallery

TO TEST ON YOUR COMPUTER
1. Extract this ZIP file.
2. Keep index.html, style.css, script.js, and the photos folder together.
3. Double-click index.html, or open it using Live Server in VS Code.

TO UPDATE YOUR EXISTING GITHUB REPOSITORY
1. Open https://github.com/khaledkhalloudi/maleeka-birthday-surprise
2. For each updated existing file, open the file and use the pencil/Edit button to replace its contents, or use Add file > Upload files and upload the updated index.html, style.css, script.js, and photos. If GitHub asks whether to replace existing files, confirm the replacement.
3. Preserve the photos folder structure.
4. Commit the changes. GitHub Pages should redeploy automatically.
5. Open https://khaledkhalloudi.github.io/maleeka-birthday-surprise/ and refresh.
